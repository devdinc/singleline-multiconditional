# Single-line Multiconditional

Skript package maintained by devdinc.

## Installation

`package install https://github.com/devdinc/singleline-multiconditional`

Requires Skript 2.15+ and skript-reflect 2.6+.

## Layout

- Source: `src/singleline-multiconditional.sk`
- Tests: `-tests/`

Part of the [devdinc Skripts collection](https://github.com/devdinc/skripts).
